# EXPO 안전체험관 QR 응모 폼

2026 산학연협력 EXPO(2026.9.30~10.2, 일산 KINTEX 2전시장 10홀) 안전체험관 부스 앞
**QR 포스터로 접속하는 휴대폰 페이지**입니다.

태블릿 체험 프로그램(`../phishing-expo`)과는 **별개 프로젝트**입니다.

---

## ⛔ 절대 원칙 — 입력값을 전송하지 않는다

참가자가 적은 이름·전화번호·생년월일은 **React 상태(메모리)에만** 존재하고,
페이지를 닫으면 사라집니다. 그게 전부입니다.

아래는 이 프로젝트에서 **영구히 금지**입니다. 코드를 고칠 때 반드시 지켜주세요.

- `fetch` · `axios` · `XMLHttpRequest` · `sendBeacon` 등 모든 서버 전송
- `<form action="...">` (반드시 `onSubmit` 에서 `preventDefault`)
- Google Forms · Formspree · Netlify Forms · Supabase 등 외부 폼 서비스
- Google Analytics · 픽셀 · 태그매니저 등 모든 추적 스크립트
- `localStorage` · `sessionStorage` · 쿠키에 입력값 저장
- 콘솔 로그에 입력값 출력 (개발 중에도 — 개발자도구를 켜보는 관람객이 반드시 있습니다)
- 입력값을 URL 주소나 QR에 담아 넘기기
- 외부 폰트·이미지 CDN (네트워크 요청이 0건이어야 확인이 쉽습니다)

## 문구 수정 (개발자 없이 가능)

화면에 보이는 글자는 전부 `src/content/` 의 JSON에 있습니다.
큰따옴표(`"`)와 쉼표(`,`)만 지우지 않으면 안전합니다.

| 파일 | 내용 |
|---|---|
| `src/content/form.json` | 응모 폼 제목·입력 항목·드롭다운 선택지·동의 문구 |
| `src/content/ui.json` | 접수 완료 화면 문구, 완료 화면 대기 시간(`holdMs`) |
| `src/content/reveal.json` | 빨간 화면 문구 + 단계별 시간(`timing`) + 소리(`sound`) |

수정 후 `npm run build` 를 한 번 돌리면 반영됩니다.

## 공개 주소 (QR이 가리키는 곳)

**https://soobin-ui.github.io/phishing-qr/**

저장소: `soobin-ui/phishing-qr` — 소스는 `main`, 배포본은 `gh-pages` 브랜치.

QR 코드는 `qr/` 폴더에 있습니다.

| 파일 | 용도 |
|---|---|
| `qr/qr-code.svg` | **인쇄용.** 벡터라 아무리 키워도 안 깨집니다 |
| `qr/qr-code.png` | 1800×1800 (300dpi 인쇄 시 15cm) |
| `qr/qr-code-transparent.png` | 배경 없는 버전 — 포스터 위에 얹을 때 |

주소가 바뀌면 `qr/make_qr.py` 안의 URL만 고치고 `python qr/make_qr.py` 를 돌리면 됩니다.

## 실행

```bash
npm install
npm run dev      # 개발 (http://localhost:5176)
npm run build    # 배포용 정적 파일 생성 → dist/
npm run preview  # 빌드 결과 확인
npm run shots    # 각 화면을 실제로 찍어서 tools/shots/ 에 PNG 로 저장
```

`npm run shots` 는 PC에 설치된 크롬으로 폼 입력부터 부스 유도까지 자동으로 돌면서
14장을 찍습니다. 화면을 눈으로 확인할 때 쓰세요. 배포본을 찍으려면:

```bash
npm run shots -- https://soobin-ui.github.io/phishing-qr/
```

**실제 휴대폰에서 테스트**: PC와 휴대폰이 같은 와이파이에 있어야 합니다.
`npm run dev` 실행 후 터미널에 뜨는 `Network:` 주소를 휴대폰 브라우저에 입력하세요.

## 문구를 고친 뒤 다시 배포하기

```bash
npm run build
git add -A && git commit -m "문구 수정" && git push
git subtree push --prefix dist origin gh-pages
```

`dist/` 는 `.gitignore` 에 있으므로 `git subtree` 가 안 되면, `dist` 안의 파일을
`gh-pages` 브랜치에 그대로 덮어쓰고 push 하면 됩니다. 1~2분 뒤 반영됩니다.

> 브라우저가 예전 화면을 물고 있으면 주소 뒤에 `?2` 처럼 아무 숫자나 붙여서 여세요.

## 화면 흐름 (총 80초)

| | 화면 | 시간 | 상태 |
|---|---|---|---|
| [1] | 응모 폼 | 55초 | ✅ Phase 1 |
| [2] | 접수 완료 | 3초 | ✅ Phase 1 |
| [3] | 빨간 화면 | 17초 | ✅ Phase 2 |
| [4] | 부스 유도 | 대기 | ✅ Phase 3 |

### [3] 빨간 화면 — 세 박자

```
경광등+사이렌+전송로그 → 큰 글씨 한 방 → 경광봉 번쩍 + 문구
```

실측 타임라인 (제출 시점 = 0초, 7개 항목을 모두 적었을 때):

| 시각 | 내용 |
|---|---|
| 0.0s | 접수 완료 (스피너 → 체크) |
| 2.6s | **경광등 + 사이렌 + 경고음.** 암전 없이 흰 화면에서 바로 |
| 2.7s | 적은 값이 0.18초 간격으로 `[전송]` 로그처럼 한 줄씩 |
| 5.0s | **"N가지 / 당신의 정보가 / 넘어갔습니다."** (40px) + 작은 안내 한 줄 |
| 8.3s | 화면이 어두워지고 **경광봉**(왼쪽 빨강·오른쪽 파랑이 번갈아 침)이 번쩍이며 **"나는 피싱 범죄로부터 / 얼마나 안전할까요?"** + 행사 안내 + 아래로 유도 |
| 11.3s | 사이렌 소리만 꺼짐 (경광봉은 계속 번쩍임) |
| 관람객이 아래로 밀면 | **"무심코 넘긴 정보 몇 줄. / 피싱 범죄로 매일 23억 원이 사라집니다."** + [다음] |
| [다음] | **[4] 부스 유도** — 태블릿 체험존 안내 + 경품 안내 |

경광봉·유도 화살표처럼 계속 움직이는 것들은 **CSS 애니메이션**입니다(`src/index.css` 의 `.qr-*`).
저사양 휴대폰에서 JS로 돌리면 끊깁니다.

### ⚠️ 경광봉 속도

속도는 두 층으로 나뉘어 있습니다.

| | 대상 | 지금 값 |
|---|---|---|
| **화면 전체를 덮는 빛** | 빔 · 화면 물듦 · 글씨 밝기 | `--qr-half` **0.35초 = 초당 2.9회** |
| **경광봉 렌즈** | 렌즈 6칸 (화면의 약 6%) | 짧게 세 번 + 길게 한 번 **연사** |

**`--qr-half` 를 0.34초보다 짧게 두지 마세요.** 화면 대부분을 덮는 적·청색 점멸이
초당 3회를 넘으면 광과민성 발작 유발 기준(WCAG 2.3.1)에 걸립니다.

다급함을 더 주고 싶으면 **렌즈 연사**(`qr-lens-red` / `qr-lens-blue`)를 손보세요.
위 기준은 '화면의 25% 이상을 덮는' 점멸에만 적용되므로 렌즈는 해당되지 않습니다.

### 글자 움직임

- 각 화면의 글자는 한 줄씩 아래에서 밀려 올라옵니다.
- 경광봉 화면의 글자는 불빛이 칠 때마다 같이 밝아졌다 어두워집니다(`.qr-lit`).
- **아래로 미는 동안** 경광봉과 글자가 서로 다른 속도로 따라 올라가고,
  다음 화면 글자는 아래에서 올라오며 진해집니다(`useScroll` 연동).

마지막 두 화면은 스크롤 스냅으로 한 화면씩 딱딱 걸립니다(중간에 어정쩡하게 멈추지 않음).
마지막 한 마디는 `reveal.json` 의 `after.lines` — 후보 문구가 바로 위 주석에 적혀 있습니다.

시간은 `reveal.json` 의 `timing` 에서 밀리초 단위로 조절합니다.

### 소리와 진동

- 사이렌·경고음은 **브라우저에서 직접 합성**합니다(`src/lib/alarm.ts`).
  음원 파일을 받아오지 않으므로 네트워크 요청이 한 건도 생기지 않습니다.
- 소리를 끄려면 `reveal.json` 의 `sound.enabled` 를 `false` 로. 볼륨은 `sound.volume`.
- ⚠️ **소리는 보너스입니다.** 아이폰은 측면 무음 스위치가 켜져 있으면 소리도 진동도
  나지 않고, 전시장은 시끄럽습니다. 화면만으로 연출이 완결되게 유지하세요.
- ⚠️ 점멸 속도는 위 「경광봉 속도」 항목을 반드시 지켜주세요.

### 빈칸 처리

- 전송 로그는 **실제로 적은 항목만** 뜹니다. 안 적은 걸 되돌려주면 그 순간 연출이 깨집니다.
- "N가지"의 N은 실제로 적은 개수입니다.
- 아무것도 안 적고 동의만 누른 경우 → "동의 한 번에, / 넘어갔습니다."
  (`reveal.json` 의 `zeroLines`)

## 디자인 원칙

- **응모 폼은 의도적으로 평범하게.** 흰 배경, 기본 입력창, 파란 제출 버튼.
  여기서 디자인 욕심을 내면 관람객이 경계하면서 기획 전체가 무너집니다.
- 애니메이션은 빨간 화면에만.
- 한글 폰트는 **기기 기본 서체**를 씁니다(추가 다운로드 0KB).
- 입력창 글자는 **16px 미만 금지** — iOS Safari가 화면을 확대해 버립니다.
- 제출 버튼 높이 **56px 이상**.
