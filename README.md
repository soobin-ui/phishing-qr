# EXPO 안전체험관 QR 응모 폼

2026 산학연협력 EXPO(2026.9.30~10.2, 일산 KINTEX 2전시장 10홀) 안전체험관 부스 앞
**QR 포스터로 접속하는 휴대폰 페이지**입니다.

태블릿 체험 프로그램(`../phishing-expo`)과는 **별개 프로젝트**입니다.

---

## ⛔ 절대 원칙 — 입력값을 전송하지 않는다

참가자가 적은 이름·전화번호·생년월일은 **React 상태(메모리)에만** 존재하고,
페이지를 닫으면 사라집니다. 그게 전부입니다.

아래는 이 프로젝트에서 **영구히 금지**입니다. 코드를 고칠 때 반드시 지켜주세요.

- `fetch` · `axios` · `XMLHttpRequest` · `sendBeacon` 등 모든 서버 전송
- `<form action="...">` (반드시 `onSubmit` 에서 `preventDefault`)
- Google Forms · Formspree · Netlify Forms · Supabase 등 외부 폼 서비스
- Google Analytics · 픽셀 · 태그매니저 등 모든 추적 스크립트
- `localStorage` · `sessionStorage` · 쿠키에 입력값 저장
- 콘솔 로그에 입력값 출력 (개발 중에도 — 개발자도구를 켜보는 관람객이 반드시 있습니다)
- 입력값을 URL 주소나 QR에 담아 넘기기
- 외부 폰트·이미지 CDN (네트워크 요청이 0건이어야 확인이 쉽습니다)

## 문구 수정 (개발자 없이 가능)

화면에 보이는 글자는 전부 `src/content/` 의 JSON에 있습니다.
큰따옴표(`"`)와 쉼표(`,`)만 지우지 않으면 안전합니다.

| 파일 | 내용 |
|---|---|
| `src/content/form.json` | 응모 폼 제목·입력 항목·드롭다운 선택지·동의 문구 |
| `src/content/ui.json` | 접수 완료 화면 문구, 완료 화면 대기 시간(`holdMs`) |
| `src/content/reveal.json` | 빨간 화면 문구 + 단계별 시간(`timing`) + 소리(`sound`) |

수정 후 `npm run build` 를 한 번 돌리면 반영됩니다.

## 실행

```bash
npm install
npm run dev      # 개발 (http://localhost:5176)
npm run build    # 배포용 정적 파일 생성 → dist/
npm run preview  # 빌드 결과 확인
```

**실제 휴대폰에서 테스트**: PC와 휴대폰이 같은 와이파이에 있어야 합니다.
`npm run dev` 실행 후 터미널에 뜨는 `Network:` 주소를 휴대폰 브라우저에 입력하세요.

## 화면 흐름 (총 80초)

| | 화면 | 시간 | 상태 |
|---|---|---|---|
| [1] | 응모 폼 | 55초 | ✅ Phase 1 |
| [2] | 접수 완료 | 3초 | ✅ Phase 1 |
| [3] | 빨간 화면 | 17초 | ✅ Phase 2 |
| [4] | 부스 유도 | 대기 | ⬜ Phase 3 |

### [3] 빨간 화면 — 세 박자

```
경광등+사이렌+전송로그 → 큰 글씨 한 방 → 사이렌 이모지 반짝 + 질문 하나
```

실측 타임라인 (제출 시점 = 0초, 7개 항목을 모두 적었을 때):

| 시각 | 내용 |
|---|---|
| 0.0s | 접수 완료 (스피너 → 체크) |
| 2.6s | **경광등 + 사이렌 + 경고음.** 암전 없이 흰 화면에서 바로 |
| 2.7s | 적은 값이 0.18초 간격으로 `[전송]` 로그처럼 한 줄씩 |
| 5.0s | **"N가지 / 당신의 정보가 / 넘어갔습니다."** (40px) + 작은 안내 한 줄 |
| 8.3s | 화면이 어두워지고 **경찰 경광등**(빨강·파랑)이 가운데서 돌며 **"오늘 하루, / 당신의 정보를 / 몇 군데에 넘기셨나요?"** + 아래로 유도 |
| 11.3s | 사이렌 소리만 꺼짐 (경광등은 계속 돎) |
| 관람객이 아래로 밀면 | **"무심코 넘긴 정보 몇 줄. / 피싱 범죄로 매일 26억 원이 사라집니다."** + [다음] |

경광등·유도 화살표 같이 계속 도는 것들은 **CSS 애니메이션**입니다(`src/index.css` 의 `.qr-*`).
저사양 휴대폰에서 JS로 돌리면 끊깁니다. 속도도 여기서 조절하세요.

마지막 두 화면은 스크롤 스냅으로 한 화면씩 딱딱 걸립니다(중간에 어정쩡하게 멈추지 않음).
마지막 한 마디는 `reveal.json` 의 `after.lines` — 후보 문구가 바로 위 주석에 적혀 있습니다.

시간은 `reveal.json` 의 `timing` 에서 밀리초 단위로 조절합니다.
이모지는 `reveal.json` 의 `question.emoji` 에서 다른 걸로 바꿀 수 있습니다.

### 소리와 진동

- 사이렌·경고음은 **브라우저에서 직접 합성**합니다(`src/lib/alarm.ts`).
  음원 파일을 받아오지 않으므로 네트워크 요청이 한 건도 생기지 않습니다.
- 소리를 끄려면 `reveal.json` 의 `sound.enabled` 를 `false` 로. 볼륨은 `sound.volume`.
- ⚠️ **소리는 보너스입니다.** 아이폰은 측면 무음 스위치가 켜져 있으면 소리도 진동도
  나지 않고, 전시장은 시끄럽습니다. 화면만으로 연출이 완결되게 유지하세요.
- ⚠️ **경광등 깜빡임은 1초 주기입니다. 이 속도를 올리지 마세요.**
  빠른 적색 점멸은 광과민성 발작을 유발할 수 있고, 불특정 다수·미성년 관람객이
  오는 부스입니다.

### 빈칸 처리

- 전송 로그는 **실제로 적은 항목만** 뜹니다. 안 적은 걸 되돌려주면 그 순간 연출이 깨집니다.
- "N가지"의 N은 실제로 적은 개수입니다.
- 아무것도 안 적고 동의만 누른 경우 → "동의 한 번에, / 넘어갔습니다."
  (`reveal.json` 의 `zeroLines`)

## 디자인 원칙

- **응모 폼은 의도적으로 평범하게.** 흰 배경, 기본 입력창, 파란 제출 버튼.
  여기서 디자인 욕심을 내면 관람객이 경계하면서 기획 전체가 무너집니다.
- 애니메이션은 빨간 화면에만.
- 한글 폰트는 **기기 기본 서체**를 씁니다(추가 다운로드 0KB).
- 입력창 글자는 **16px 미만 금지** — iOS Safari가 화면을 확대해 버립니다.
- 제출 버튼 높이 **56px 이상**.
